# Issues Guidelines

We classify issues into three categories:

- **[Feature Request](#feature-request)**: Propose a new feature or enhancement.
- **[Task](#task)**: Subtasks or implementation details linked to a Feature Request.
- **[Bug Report](#bug-report)**: Describe a reproducible bug that needs fixing.
